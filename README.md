# Atul Yado — Portfolio

A lightweight, static portfolio for GitHub Pages. Open `index.html` locally to preview it. There is no build step.

## Publish on GitHub Pages

1. Create a **public** GitHub repository named `WebPortfolio` under `atulyado`.
2. Push this folder to the repository's `main` branch.
3. In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then save.
4. The expected address is `https://atulyado.github.io/WebPortfolio/`.

GitHub may take several minutes to publish the first version. All asset paths are relative, so the site works at a project URL.

## Updating

Edit `index.html` or `styles.css`, then commit and push to `main`. The resume and project folio are copied into `assets/`; replace those copies if the source PDFs change.
